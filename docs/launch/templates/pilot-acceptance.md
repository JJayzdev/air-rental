| Bước | Kết quả mong đợi của bài | Kết quả quan sát | Đạt / một phần / chưa đạt | Mã ảnh/log không nhạy cảm | Ghi chú |
|---|---|---|---|---|---|
| Catalog hiển thị nhãn sample | Trang catalog có chú thích mẫu; sản phẩm có badge `MẪU`. |  |  |  |  |
| Tìm kiếm/lọc/sắp xếp | Danh sách thay đổi theo từ khóa, danh mục và lựa chọn sắp xếp. |  |  |  |  |
| Chi tiết giải thích mẫu không bookable | Trang chi tiết nêu dữ liệu tham khảo và không cho đặt mẫu. |  |  |  |  |
| Dùng keyboard tab, focus nhìn thấy, nhãn điều khiển và alt text | Có thể theo dõi focus; điều khiển có tên; hình có alt text phù hợp. |  |  |  |  |
| Kiểm tra bố cục trên kích thước màn hình đã chọn | Nội dung và điều khiển không bị che/mất ở viewport đã chọn. |  |  |  |  |
| Trình bày kiến trúc / luồng dữ liệu | Mô tả đúng ranh giới browser/server/Supabase và điều kiện cần cho luồng. |  |  |  |  |
